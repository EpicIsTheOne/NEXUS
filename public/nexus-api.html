NEXUS API v1

NEXUS API docs

Use the AIChat/NEXUS character system from scripts and apps. This page shows how to log in, get characterId values, create a history, send normal chat requests, and stream responses from Python.

Back to app Open characters JSON Open health JSON

NEXUS base path: https://your-domain.example/nexus/api/nexus
TTS tagger endpoint: https://your-domain.example/nexus/api/tts/tag
Tagged audio endpoint: https://your-domain.example/nexus/api/tts/audio
Auth for v1 now supports either the same login session as the site or a Bearer NEXUS API key created from the admin settings panel. Admins can also disable the API globally.

Endpoints

MethodPathUse
GET/api/nexus/healthBasic status check
GET/api/nexus/charactersList characters and their IDs
POST/api/nexus/historiesCreate a new saved history
GET/api/nexus/histories/:historyIdFetch one saved history
POST/api/nexus/chatNormal or streaming chat
POST/api/tts/tagReturn the same Fish-style tagged TTS text used by chat voice playback
POST/api/tts/audioTag text, synthesize it with a Fish Audio voice ID, and return audio bytes

How to get the IDs you need

  • characterId: call GET /api/nexus/characters. Every returned character has an id.
  • historyId: call POST /api/nexus/histories. The response returns historyId.
  • You can also skip pre-creating a history and use createHistory: true in POST /api/nexus/chat.

Python example: login and get character IDs

import requests

BASE = "https://your-domain.example/nexus"
s = requests.Session()

# 1) Log in using the same account you use on the site
login = s.post(
    f"{BASE}/api/auth/login",
    json={"username": "Epic", "password": "YOUR_PASSWORD"},
)
login.raise_for_status()
print("Logged in:", login.json())

# 2) Get all characters
characters_res = s.get(f"{BASE}/api/nexus/characters")
characters_res.raise_for_status()
characters = characters_res.json()["characters"]

# 3) Print names + IDs so you can pick one
for c in characters[:10]:
    print(c["name"], "->", c["id"])

character_id = characters[0]["id"]
print("Using characterId:", character_id)

Python example: create a history and get historyId

s.post(f"{BASE}/api/auth/login", json={"username": "Epic", "password": "YOUR_PASSWORD"}).raise_for_status()

    f"{BASE}/api/nexus/histories",
    json={
        "characterId": character_id,
        "name": "My Python test history"
    },
)

history = history_res.json()

history_id = history["historyId"]
print("historyId:", history_id)
print(history)

Python example: streaming

Streaming uses Server-Sent Events style output. Watch for event: delta chunks and the final event: done.

import json
import requests

BASE = "https://your-domain.example/nexus"
s = requests.Session()

s.post(f"{BASE}/api/auth/login", json={"username": "Epic", "password": "YOUR_PASSWORD"}).raise_for_status()

character_id = "PUT_CHARACTER_ID_HERE"
history_id = "PUT_HISTORY_ID_HERE"

with s.post(
    f"{BASE}/api/nexus/chat",
    json={
        "characterId": character_id,
        "historyId": history_id,
        "message": "Say hello in one short sentence.",
        "stream": True,
    },
    stream=True,
) as r:
    r.raise_for_status()
    current_event = None

    for raw_line in r.iter_lines(decode_unicode=True):
        if not raw_line:
            continue

        if raw_line.startswith("event: "):
            current_event = raw_line[len("event: "):]
        elif raw_line.startswith("data: "):
            payload = json.loads(raw_line[len("data: "):])

            if current_event == "meta":
                print("model:", payload)
            elif current_event == "delta":
                print(payload.get("delta", ""), end="", flush=True)
            elif current_event == "retry":
                print("\nretry info:", payload)
            elif current_event == "done":
                print("\n\nfinal payload:")
                print(payload)
            elif current_event == "error":
                print("\nerror:", payload)

TTS tagger API

The TTS tagger endpoint takes raw dialogue or RP-style text and returns the same tagged text the chat voice system sends into Fish TTS. This is useful when you want to preview or reuse the message tagger without generating audio.

For now, this endpoint uses the normal AIChat login session cookie. No API key is required or enabled.

MethodPathUse
POST/api/tts/tagTag text for TTS delivery

Request body

FieldTypeRequiredNotes
textstringyesThe raw text to tag. Can include quoted dialogue and asterisk narration.
characterIdstringnoOptional. When provided, the tagger can use that character's settings, including narration-reading behavior.
includeAsteriskNarrationbooleannoDefaults to false. When true, asterisk narration is included in the spoken/tagged text.
streambooleannoWhen true, the endpoint attempts Fish realtime streaming before falling back to full audio generation.

Example request

POST https://your-domain.example/nexus/api/tts/tag
Content-Type: application/json

{
  "text": "*Miyabi lets out a loud gasp.* \"AAAAAAAAAAHHHNNNNN!!!\"",
  "characterId": "local-miyabi"
}

Example response

{
  "ok": true,
  "input": "*Miyabi lets out a loud gasp.* \"AAAAAAAAAAHHHNNNNN!!!\"",
  "text": "[loud moan] [loud moan] [loud moan] [loud] [loud] Aaaahn!!!!!",
  "taggedText": "[loud moan] [loud moan] [loud moan] [loud] [loud] Aaaahn!!!!!",
  "tags": ["loud moan", "loud"],
  "tag": "[loud moan] [loud moan] [loud moan] [loud] [loud]",
  "spokenText": "AAAAAAAAAAHHHNNNNN!!!"
}

Python example: tag text for TTS

import requests

BASE = "https://your-domain.example/nexus"
s = requests.Session()

# Uses the same site login session. No API key is required/enabled right now.
s.post(
    f"{BASE}/api/auth/login",
    json={"username": "Epic", "password": "YOUR_PASSWORD"},
).raise_for_status()

payload = {
    "text": "*Miyabi lets out a loud gasp.* \"AAAAAAAAAAHHHNNNNN!!!\"",
    "characterId": "local-miyabi",
}

res = s.post(f"{BASE}/api/tts/tag", json=payload)
res.raise_for_status()

data = res.json()
print("Tagged text:", data["taggedText"])
print("Tags:", data["tags"])
print("Spoken text:", data["spokenText"])

Tagged Fish audio API

This endpoint takes raw text plus a Fish Audio voice/reference ID, runs the same message tagger used by chat voice playback, sends the tagged text to Fish, and returns the audio file directly.

For now, this endpoint uses the normal AIChat login session cookie. No API key is required or enabled.

MethodPathReturns
POST/api/tts/audioAudio bytes, usually audio/mpeg for MP3

Request body

FieldTypeRequiredNotes
textstringyesRaw text to tag and synthesize.
voiceIdstringyesFish Audio voice/reference ID. Aliases fishReferenceId and referenceId also work.
formatstringnomp3, wav, opus, or pcm. Defaults to mp3.
latencystringnolow, normal, or balanced. Defaults to low.
characterIdstringnoOptional context for the tagger. The voice still comes from voiceId.
includeAsteriskNarrationbooleannoDefaults to false. When true, asterisk narration is included in the spoken/tagged text.
streambooleannoWhen true, the endpoint attempts Fish realtime streaming before falling back to full audio generation.

Response headers

  • Content-Type: audio content type, usually audio/mpeg.
  • X-TTS-Tagged-Text: URL-encoded tagged text that was sent to Fish.
  • X-TTS-Emotion-Tag: the main Fish-style tag string.
  • X-TTS-Tags: URL-encoded JSON array of tags.
  • X-TTS-Spoken-Text: URL-encoded cleaned spoken text.
  • X-TTS-Mode: stream, full, or cache.

Example request

POST https://your-domain.example/nexus/api/tts/audio
Content-Type: application/json

{
  "text": "*She sighs softly.* \"Fine, I’ll help.\"",
  "voiceId": "98655a12fa944e26b274c535e5e03842",
  "format": "mp3"
}

Python example: generate tagged Fish audio

from urllib.parse import unquote
import requests

BASE = "https://your-domain.example/nexus"
s = requests.Session()

# Uses the same site login session. No API key is required/enabled right now.
s.post(
    f"{BASE}/api/auth/login",
    json={"username": "Epic", "password": "YOUR_PASSWORD"},
).raise_for_status()

payload = {
    "text": "*She sighs softly.* \"Fine, I’ll help.\"",
    "voiceId": "98655a12fa944e26b274c535e5e03842",
    "format": "mp3",
}

res = s.post(f"{BASE}/api/tts/audio", json=payload)
res.raise_for_status()

with open("tagged-voice.mp3", "wb") as f:
    f.write(res.content)

print("Saved tagged-voice.mp3")
print("Tagged text:", unquote(res.headers.get("X-TTS-Tagged-Text", "")))
print("Tags:", unquote(res.headers.get("X-TTS-Tags", "[]")))
print("Spoken text:", unquote(res.headers.get("X-TTS-Spoken-Text", "")))

Python example: tag first, then generate audio

from urllib.parse import unquote
import requests

BASE = "https://your-domain.example/nexus"
s = requests.Session()
s.post(f"{BASE}/api/auth/login", json={"username": "Epic", "password": "YOUR_PASSWORD"}).raise_for_status()

text = "*She laughs softly.* \"You’re impossible.\""
voice_id = "98655a12fa944e26b274c535e5e03842"

# Preview the tagger output
preview = s.post(f"{BASE}/api/tts/tag", json={"text": text})
preview.raise_for_status()
print("Preview:", preview.json()["taggedText"])

# Generate audio using the same tagger pipeline server-side
audio = s.post(
    f"{BASE}/api/tts/audio",
    json={"text": text, "voiceId": voice_id, "format": "mp3"},
)
audio.raise_for_status()
open("voice.mp3", "wb").write(audio.content)
print("Audio tagged as:", unquote(audio.headers.get("X-TTS-Tagged-Text", "")))

Quick notes

  • If you already know the site account login, you can use it directly from Python with requests.Session().
  • If you want a fresh saved thread first, call POST /api/nexus/histories.
  • If you just want to fire one request and save it automatically, use createHistory: true.
  • If you need a specific history later, fetch it with GET /api/nexus/histories/:historyId?characterId=....
